O Claude Code é a ferramenta da Anthropic que coloca o Claude para trabalhar dentro do seu projeto: ele lê os arquivos, edita o código, roda comandos e usa o Git a partir de pedidos em linguagem natural. Este tutorial segue a documentação oficial para mostrar quem pode usar, como instalar no macOS, Linux e Windows, como fazer login, quais são os primeiros comandos e, principalmente, que cuidados tomar antes de deixar uma IA mexer no seu código. Se o que você quer é tirar dúvidas de programação colando trechos no chat, o guia certo é o de [Claude para programação](/artigos/claude-para-programacao).

## O que é o Claude Code

Segundo a [documentação oficial](https://code.claude.com/docs/en/overview), o Claude Code é "an agentic coding tool that reads your codebase, edits files, runs commands, and integrates with your development tools". Na prática, em vez de copiar código para um chat e colar a resposta de volta, você descreve a tarefa e ele localiza os arquivos, propõe e aplica as mudanças e roda os testes, se o projeto tiver testes.

Ele funciona em vários lugares:

- **Terminal** (CLI), o foco deste guia;
- **IDEs**: VS Code, Cursor e JetBrains;
- **App desktop**;
- **Navegador**, em claude.ai/code.

A documentação também cita integrações com Slack, GitHub Actions e GitLab.

### Claude Code e chat: a diferença em uma tabela

| Aspecto | Chat do Claude | Claude Code |
|---|---|---|
| Onde roda | Web, desktop e celular | Terminal, IDE, desktop e web |
| Acesso ao seu projeto | Só o que você cola ou anexa | Lê os arquivos do repositório |
| Edita arquivos | Não; você copia a resposta | Sim, direto no projeto |
| Executa comandos | Não no seu computador | Sim, no seu ambiente |
| Plano | Todos, inclusive o Free | Pro, Max, Team, Enterprise ou API |

## Quais planos incluem o Claude Code

- **Pro e Max**: incluído. O uso do Claude Code conta no mesmo limite do chat, segundo a [central de ajuda da Anthropic](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-or-max-plan).
- **Team e Enterprise**: "Claude Code is included with every Team plan seat", e ele também vem no assento dos planos Enterprise novos e self-serve.
- **Claude Console (API)**: dá para usar com créditos pré-pagos, pagando por token. No primeiro login, é criado automaticamente um workspace "Claude Code" no Console para acompanhar os custos.
- **Provedores de nuvem**: empresas podem usar via Amazon Bedrock, Google Cloud e Microsoft Foundry.
- **Free**: não inclui o Claude Code.

Para comparar valores e limites, veja o guia de [planos do Claude](/artigos/claude-planos-precos-comparacao). Preços e limites podem mudar; consulte a [página oficial](https://claude.com/pricing).

**Modelo padrão:** no Claude Code, o padrão é o Opus 5.5 para contas Pro, Max, Team, Enterprise e API. Os modelos Fable nunca são padrão e precisam ser escolhidos manualmente; no Pro, eles exigem créditos pagos à parte.

## Pré-requisitos

1. Um terminal aberto (Terminal no macOS e Linux; PowerShell ou Prompt de Comando no Windows).
2. Um projeto de código para trabalhar, de preferência já versionado com Git.
3. Uma conta Pro, Max, Team, Enterprise ou do Claude Console.
4. No Windows nativo, a documentação recomenda instalar o [Git for Windows](https://git-scm.com/downloads/win). Quem usa WSL não precisa dele.

## Passo 1: instale o Claude Code

Rode **um** dos comandos abaixo, conforme o seu sistema. O instalador nativo é o método recomendado pela Anthropic e se atualiza sozinho em segundo plano.

**macOS, Linux e WSL:**

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows PowerShell:**

```powershell
irm https://claude.ai/install.ps1 | iex
```

**Windows Prompt de Comando (CMD):**

```batch
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

Se preferir um gerenciador de pacotes:

```bash
# Homebrew (macOS/Linux)
brew install --cask claude-code
```

```powershell
# WinGet (Windows)
winget install Anthropic.ClaudeCode
```

Instalações via Homebrew e WinGet **não se atualizam sozinhas**. Para atualizar, use `brew upgrade claude-code` ou `winget upgrade Anthropic.ClaudeCode` de tempos em tempos.

**Dois erros comuns no Windows:** se aparecer `The token '&&' is not a valid statement separator`, você está no PowerShell usando o comando do CMD; se aparecer `'irm' is not recognized`, você está no CMD usando o comando do PowerShell. O PowerShell mostra `PS C:\` no início da linha.

## Passo 2: confirme a instalação

Abra uma **nova** janela do terminal e rode:

```bash
claude --version
```

Se aparecer um número de versão seguido de "(Claude Code)", está tudo certo. Se o terminal disser que o comando `claude` não foi encontrado, a pasta de instalação ainda não está no PATH; a documentação oficial tem uma página de solução de problemas de instalação para esse caso.

## Passo 3: faça login

Entre na pasta do projeto e inicie o Claude Code:

```bash
cd /caminho/do/seu/projeto
claude
```

Na primeira vez, ele pede login. Com conta de assinatura ou do Console, siga as instruções para concluir a autenticação no navegador. As credenciais ficam salvas, então não é preciso repetir o login. Para trocar de conta depois, digite dentro da sessão:

```text
/login
```

Se a variável de ambiente `ANTHROPIC_API_KEY` estiver definida, o Claude Code pula o login e pede que você aprove o uso dessa chave. Atenção: se você tem assinatura e também uma chave de API configurada no sistema, confira qual das duas está sendo usada para não pagar por token sem querer.

## Passo 4: seus primeiros pedidos

Ao iniciar, o Claude Code mostra a versão, o modelo atual e a pasta de trabalho. Digite `/help` para ver os comandos disponíveis. Os exemplos da documentação oficial estão em inglês; abaixo estão versões em português dos mesmos pedidos.

Comece entendendo o projeto, sem alterar nada:

```text
o que este projeto faz?
```

```text
quais tecnologias este projeto usa e onde fica o ponto de entrada principal?
```

```text
explique a estrutura de pastas
```

Depois, uma mudança pequena e fácil de conferir:

```text
adicione uma função hello world no arquivo principal
```

E o Git, em linguagem natural:

```text
quais arquivos eu alterei?
```

```text
crie uma branch chamada feature/teste-claude
```

```text
faça o commit das minhas alterações com uma mensagem descritiva
```

### Exemplo prático: corrigir um bug com plano antes

Um pedido bem descrito economiza idas e voltas. Compare:

- Vago: "corrija o bug do login".
- Específico, no estilo que a documentação recomenda:

```text
Há um bug no login: depois de digitar a senha errada, a tela fica em branco
em vez de mostrar a mensagem de erro.
Antes de alterar qualquer arquivo, investigue a causa e me apresente um plano
com os arquivos que pretende mudar. Espere minha aprovação.
Depois de corrigir, rode os testes existentes e me mostre o resultado.
```

Para tarefas grandes, divida em etapas numeradas (por exemplo: 1. criar a tabela; 2. criar o endpoint; 3. criar a tela) e revise cada uma antes de seguir.

## Comandos essenciais

Comandos que você roda **no terminal**, para abrir o Claude Code:

| Comando | O que faz |
|---|---|
| `claude` | Inicia o modo interativo |
| `claude "tarefa"` | Inicia o modo interativo já com um pedido |
| `claude -p "pergunta"` | Faz uma consulta única e encerra |
| `claude -c` | Continua a conversa mais recente da pasta atual |
| `claude -r` | Retoma uma conversa anterior |
| `claude --version` | Mostra a versão instalada |

Comandos que você digita **dentro da sessão**:

| Comando | O que faz |
|---|---|
| `/help` | Mostra os comandos disponíveis |
| `/clear` | Limpa o histórico da conversa |
| `/login` | Troca de conta ou refaz a autenticação |
| `/resume` | Continua uma conversa anterior |
| `/exit` | Sai do Claude Code |

Atalhos úteis: digite `/` para ver comandos e skills disponíveis, use Tab para completar comandos, a seta para cima para o histórico e Shift+Tab para alternar o modo de permissão. A lista completa está na referência de CLI da documentação oficial.

## Segurança: leia antes de usar em um projeto real

O ponto mais importante deste guia: o Claude Code tem **modos de permissão**. Em alguns, ele pede aprovação antes de editar arquivos ou rodar comandos; nos mais autônomos, ele edita arquivos e executa comandos **sem perguntar a cada passo**. O modo inicial pode variar conforme a versão instalada, as suas configurações e as regras da sua empresa, por isso confira no início da sessão qual modo está ativo (o [quickstart oficial](https://code.claude.com/docs/en/quickstart) e a documentação explicam as opções).

Checklist antes de cada sessão:

1. **Versione tudo com Git e faça um commit antes de começar.** Assim, qualquer mudança indesejada pode ser desfeita.
2. **Trabalhe em uma branch separada**, nunca direto na principal.
3. **Escolha o modo de permissão.** Pressione Shift+Tab para trocar o modo da sessão se quiser aprovar ações uma a uma, principalmente em projetos que você ainda não conhece bem.
4. **Não abra o Claude Code em pastas com segredos soltos** (arquivos `.env` com senhas de produção, chaves privadas, backups de banco com dados de clientes). Ele lê os arquivos do projeto conforme precisa.
5. **Desconfie de repositórios de terceiros.** Arquivos de um projeto desconhecido podem conter instruções escritas para enganar assistentes de IA. Revise o que a ferramenta pretende executar.
6. **Nunca aponte para produção.** Rode em ambiente de desenvolvimento ou homologação; nada de credenciais de banco de produção na máquina onde a IA executa comandos.
7. **Revise o diff antes do commit.** Peça "mostre um resumo de tudo que você alterou" e confira com `git diff`.
8. **Rode os testes você também.** O fato de o Claude dizer que os testes passaram não substitui a sua verificação no pipeline de CI.

Sobre privacidade: nas contas Free, Pro e Max, a configuração Model Improvement define se os dados, **incluindo os do Claude Code**, podem ser usados para treinar modelos. Nos planos comerciais (Team, Enterprise e API), não há treinamento por padrão. Os detalhes estão no guia [Claude e segurança de dados](/artigos/claude-seguranca-privacidade-dados).

## Casos de uso que valem o investimento

- **Entrar em um projeto novo**: pedir um mapa da arquitetura antes de ler o código.
- **Corrigir bugs que envolvem vários arquivos**: descrever o sintoma e pedir a investigação.
- **Escrever testes** para funções que ainda não têm cobertura.
- **Refatorar código legado**, com a regra explícita de manter o comportamento e rodar os testes a cada etapa.
- **Atualizar a documentação**, como o README com as instruções de instalação.
- **Revisar as próprias alterações** antes de abrir um pull request.

## Quando NÃO usar o Claude Code

- Para uma dúvida pontual de sintaxe ou um conceito: o chat resolve com menos consumo do limite.
- Em projetos sem controle de versão: primeiro rode `git init` e faça um commit.
- Em máquinas com acesso direto a sistemas de produção.
- Quando a política da empresa não permite enviar o código-fonte a serviços externos.
