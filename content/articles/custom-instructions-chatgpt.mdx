# Custom Instructions do ChatGPT: personalize sua IA

Imagine ter um assistente que já sabe exatamente quem você é, o que você faz e como prefere receber informações — sem você precisar explicar tudo isso toda vez que começa uma conversa. É exatamente isso que as **Custom Instructions** (Instruções Personalizadas) do ChatGPT proporcionam.

Esse é um dos recursos mais subestimados do ChatGPT. A maioria das pessoas ainda começa cada conversa do zero, sem aproveitar essa funcionalidade que pode transformar completamente a qualidade das respostas que você recebe.

## O que são Custom Instructions?

As Custom Instructions são um conjunto de **instruções fixas** que você configura uma vez e que se aplicam a todas as suas conversas com o ChatGPT. Elas funcionam como uma espécie de "briefing permanente" que a IA recebe antes de qualquer troca de mensagens.

Há dois campos principais nas Custom Instructions:

1. **O que o ChatGPT deve saber sobre você**: informações sobre quem você é, sua profissão, contexto, preferências pessoais
2. **Como o ChatGPT deve responder**: formato das respostas, tom, nível de detalhe, idioma, etc.

Esses campos têm limite de aproximadamente 1.500 caracteres cada, então você precisa ser direto e objetivo.

## Como ativar as Custom Instructions

### No computador (navegador):

1. Acesse [chat.openai.com](https://chat.openai.com)
2. Clique no seu ícone de perfil (canto inferior esquerdo)
3. Selecione **"Personalizar ChatGPT"** ou **"Custom Instructions"**
4. Preencha os dois campos
5. Clique em **Salvar**

### No celular (app):

1. Abra o app do ChatGPT
2. Toque no ícone de perfil
3. Acesse **Configurações > Instruções Personalizadas**
4. Preencha e salve

## O que colocar nas Custom Instructions

Aqui está a parte mais importante do artigo: **o que escrever** nesses campos para realmente fazer diferença.

### Campo 1: Quem você é (o que o ChatGPT deve saber)

Este campo deve conter informações que mudam o contexto das respostas. Exemplos de informações úteis:

- Sua profissão ou área de atuação
- Nível de conhecimento técnico
- País/cidade (relevante para leis, cultura, referências locais)
- Projetos atuais relevantes
- Áreas de interesse
- Idioma preferido

**Exemplo para um desenvolvedor:**

```
Sou desenvolvedor de software sênior com foco em backend, 
especializado em Python e Node.js. Trabalho com startups de fintech 
no Brasil. Tenho 8 anos de experiência. Conheço bem conceitos 
avançados de arquitetura de software, microsserviços e cloud (AWS).
Uso Python 3.11+ e estou familiarizado com FastAPI, SQLAlchemy e Docker.
```

**Exemplo para um estudante:**

```
Sou estudante do 2º ano de Medicina na USP, São Paulo. 
Estou focando em anatomia e fisiologia este semestre. 
Tenho base sólida em ciências básicas mas ainda estou 
desenvolvendo o raciocínio clínico. 
Prefiro aprender com casos práticos e analogias visuais.
```

**Exemplo para um empreendedor:**

```
Sou empreendedor no setor de e-commerce, dono de uma loja 
de produtos naturais online com faturamento de R$50k/mês. 
Tenho 3 funcionários. Tenho dificuldade com marketing digital 
mas sou bom em vendas e relacionamento com clientes. 
Fico no Brasil, foco no mercado nacional.
```

### Campo 2: Como responder (formato das respostas)

Este campo instrui o ChatGPT sobre o **estilo** das respostas. Aqui você controla:

**Extensão e formato:**
```
Prefiro respostas concisas e diretas. Use tópicos e listas 
quando listar itens. Para explicações técnicas, use exemplos 
de código sempre que possível. Não precisa de introduções longas 
ou frases como "Ótima pergunta!".
```

**Tom e linguagem:**
```
Use linguagem técnica sem simplificar. Trate-me como um colega 
profissional. Pode usar jargões da área. Português brasileiro, informal.
```

**Formato específico:**
```
Para tutoriais: comece com uma visão geral rápida, depois os passos numerados. 
Para análises: comece com a conclusão principal, depois os argumentos.
Para código: sempre inclua comentários explicando a lógica.
```

## Exemplos prontos de Custom Instructions

### Para jornalistas e redatores:

**Campo 1:**
```
Sou jornalista especializado em tecnologia e negócios para o mercado 
brasileiro. Escrevo para o público executivo de médias e grandes empresas. 
Meu foco atual é inteligência artificial, fintechs e transformação digital.
Prefiro linguagem clara, sem jargão desnecessário, mas com precisão técnica.
```

**Campo 2:**
```
Seja direto e factual. Prefiro listas de tópicos para informações 
estruturadas. Quando pedir ideias de pautas ou ângulos editoriais, 
dê de 5 a 10 opções. Para textos, use parágrafos curtos (máx 3 linhas).
Nunca use linguagem corporativa vazia. Português brasileiro, tom neutro/analítico.
```

### Para professores:

**Campo 1:**
```
Sou professora de história no ensino médio em Belo Horizonte, MG. 
Trabalho com alunos de 14 a 17 anos. Tenho foco em metodologias ativas 
e gamificação. Sigo a BNCC. Tenho turmas de 35 alunos em média.
```

**Campo 2:**
```
Quando pedir atividades, dê o material completo: enunciado, gabarito 
e sugestão de condução em sala. Para planos de aula, siga o formato: 
objetivo, materiais, desenvolvimento (passo a passo), avaliação. 
Nível linguístico adequado para adolescentes. Sugira sempre adaptações 
para alunos com dificuldades de aprendizagem.
```

### Para advogados:

**Campo 1:**
```
Sou advogado especializado em direito empresarial e contratos, 
com OAB/SP. Atendo principalmente PMEs e startups no Brasil. 
Tenho 12 anos de experiência. Conheço bem o Código Civil, 
CLT e legislação tributária básica.
```

**Campo 2:**
```
Respostas técnicas com citação de artigos de lei quando relevante. 
Sempre mencione que é orientação geral, não substitui consulta jurídica. 
Para análise de contratos: organize por cláusulas e riscos. 
Use linguagem técnica jurídica. Português formal.
```

## Dicas avançadas para Custom Instructions melhores

### 1. Teste e ajuste sempre

Depois de configurar, converse com o ChatGPT sobre vários tópicos e veja se as respostas estão no estilo que você queria. Ajuste os campos conforme necessário.

### 2. Atualize quando sua situação mudar

Mudou de emprego? Começou um projeto novo? Está estudando para uma prova específica? Atualize suas Custom Instructions para refletir o contexto atual.

### 3. Use verbos de ação no Campo 2

Em vez de "quero respostas curtas", escreva "limite as respostas a 3 parágrafos". Quanto mais específico e imperativo, melhor.

### 4. Não desperdice espaço com o óbvio

O ChatGPT já sabe ser educado, já sabe usar português. Use o espaço limitado para instruções que realmente mudam o comportamento.

### 5. Combine com a Memória

As Custom Instructions são fixas; a Memória é dinâmica. Use as duas juntas: Custom Instructions para preferências permanentes, Memória para contextos que mudam.

## Limitações das Custom Instructions

- **Não funcionam em todos os contextos**: em alguns GPTs personalizados e plugins, podem ser ignoradas
- **Limite de caracteres**: você tem cerca de 1.500 caracteres por campo — seja conciso
- **Podem ser ignoradas em respostas muito específicas**: se o pedido for muito contraditório com suas instruções, o ChatGPT pode priorizar a tarefa em si
- **Não transferem entre contas**: cada conta tem suas próprias configurações

## Conclusão

As Custom Instructions são uma das configurações mais poderosas do ChatGPT e, surpreendentemente, ainda são ignoradas pela maioria dos usuários. Dedique 15 minutos para configurar as suas — esse tempo vai se pagar em cada conversa que você tiver a partir de agora.

Pense assim: você está essencialmente criando o seu assistente ideal. Quanto mais cuidado você tiver com essa configuração, melhor esse assistente vai te atender.

Se você já usa o ChatGPT regularmente, configurar as Custom Instructions hoje é provavelmente a coisa de maior impacto que você pode fazer para melhorar sua experiência imediatamente.
